Cómo funciona

  • El archivo debe tener una fila por aviso de la base de predicción (3.029) y dos columnas: id y piscina_predicha, con valores 0 o 1 (sin probabilidades y sin NA).
  • Las métricas se calculan sobre una mitad de la base de predicción, escogida al azar. No se informa qué avisos la componen.
  • La otra mitad —que esta página no conoce— es la que define el ranking del curso. Verificar aquí no gasta nada: puede subir el archivo cuantas veces quiera.
